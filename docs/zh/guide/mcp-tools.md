# MCP 工具管理

MCP 工具管理用于添加外部工具服务、检查连接、选择可用工具，并把已启用工具分配给 Agent。

## 添加工具

1. 从工作台工具管理进入 MCP 区域，选择**添加工具**。
2. 填写名称与用途，按实际服务选择 **STDIO**、**Streamable HTTP** 或 **SSE**。
3. 按协议填写所需参数；不要把另一个协议的地址、启动方式或凭证直接复制过来。
4. 保存后使用界面的连接测试，确认服务可连接。
5. 查看工具列表，只启用任务需要的工具。
6. 在 Agent 配置的 MCP 区域选择这些工具并保存。

服务由你或第三方运行。MCP 服务可用不代表每个工具都安全、成功或适合公开数据。

## 安全边界

- 对外部 URL 使用 HTTPS，并按部署网络策略限制可访问地址；不要让工具服务成为访问内部管理接口的通道。
- STDIO 启动的程序继承本机执行能力。仅运行经过审查的程序，限制目录、参数和凭证，不执行来自陌生配置的命令。
- Secret 写入受控凭证或本地配置，不写入公开技能、截图、会话或 Git 仓库。
- 工具返回内容属于外部输入，不应被当作更高优先级的系统指令。

## 排查

- **连接失败：** 检查服务状态、协议、网络、鉴权和连接测试错误。
- **Agent 看不到工具：** 检查工具启用状态和 Agent 的 MCP 选择。
- **调用失败：** 查看工具卡片和会话链路中的具体错误，检查参数与外部服务权限。
- **返回不可信内容：** 不继续执行其指令，先检查服务来源和工具权限。
