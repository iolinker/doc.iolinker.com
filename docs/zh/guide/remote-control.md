# 企微 Agent 遥控

企微遥控通过长连接通道，让获准的企业微信用户与指定 Agent 对话。它不是旧机器人触发器，也不是单纯的企业微信消息发送节点。

## 前提

- 有可用的 Agent 和模型配置。
- 已在企业微信管理后台准备支持该通道的 Bot ID 与长连接 Secret。
- 当前网络允许建立所需长连接；能否连接以通道状态为准。
- 了解 Agent 的工具、工作目录和可访问数据范围。

## 添加通道

1. 从 Agent 卡片的远程通道入口，或工作台顶部入口进入远程通道管理。
2. 选择**添加遥控**，选择 Agent 并填写通道名称。
3. 填入 Bot ID 和 Secret。不要把真实值放入文档、截图或公开配置。
4. 配置用户白名单，明确允许使用该 Agent 的用户；只有确实理解风险时才考虑 `*`。
5. 选择**连接并保存**，确认通道进入可用状态后，用白名单中的账号发送一个无副作用测试消息。

通道的启用／停用控制远程访问。会话可在 Web 端继续查看，但并不意味着远程用户天然拥有 Web 管理权限。

## 与其他企业微信能力的区别

- **企微遥控**：接收远程用户指令，驱动 Agent，回复对话结果。
- **旧企微机器人触发器**：历史工作流入口，新建入口已隐藏。
- **发送企业微信消息节点**：工作流向外发送消息，不等于建立 Agent 遥控。

## 安全与排查

白名单是重要边界，但不应替代最小工具授权。通道异常时先停用，检查 Bot 配置、白名单、网络和通道错误信息，再检查 Agent 会话与工具结果。Secret 泄露后应在对应平台轮换，不能只删除截图。
