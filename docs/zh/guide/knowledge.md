# 知识库与检索

知识库用于向 Agent 或工作流提供可检索的参考资料，不是把整份文件直接交给模型。

## 创建知识库

1. 进入知识库管理，选择新建并填写名称、描述。
2. 上传有使用权的资料，检查文档是否含秘密、个人信息或不宜发送给外部模型的内容。
3. 选择文本或向量检索能力，按界面配置分块与检索参数。
4. 如启用向量能力，选择对应的 LLM／Embedding 模型配置和向量存储；具体选项以当前部署为准。
5. 等待索引完成，检查分片或检索结果，再分配给 Agent。

文本检索和向量检索的模型依赖不同。不能因为文件上传成功就认为索引、向量化和检索全部可用。

## 在 Agent 中使用

1. 在 Agent 配置的**知识库**区域选择目标库。
2. 保存后提出一个可以从资料中核验的问题。
3. 检查回答是否符合资料，并在可用时查看检索片段或调用链路。
4. 更新资料后重新核对索引状态，避免沿用旧内容。

需要在工作流中显式查询时，使用[知识检索节点](../knowledge_retrieval)，可选择向量、关键词或混合检索；AI 摘要还需要对应模型配置。

## 权限与数据

- 将资料分块并发送给外部模型前，确认服务商的数据处理方式。
- 不把不同密级的资料混在同一个公共知识库中。
- 知识库可访问不等于内容真实；外部文档中的指令仍属于不可信输入。
- 删除或更新知识库前检查 Agent 和工作流引用，避免影响已有任务。
