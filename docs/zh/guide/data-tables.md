# 数据表管理

数据表用于管理结构化记录，并通过工作流节点读写。本页介绍表管理，不把它等同于完整多维表格或任意业务页面搭建。

## 创建表与字段

1. 从工作流模式的**数据表**入口选择**新建**。
2. 创建表并设置名称、描述等基础信息。
3. 添加字段，选择界面提供的类型、名称与约束。
4. 保存后添加少量测试记录，确认字段和值符合预期。

已有数据时修改字段类型或约束前先检查影响；本页不承诺无损失类型转换或无限规模存储。

## 管理记录

- 新增、编辑、删除行数据，删除前确认记录不再被流程使用。
- 使用筛选、排序、分组或搜索定位记录；这些视图操作不改变原始字段定义。
- 使用导入、导出时检查格式、字段映射和文件大小；界面能力受当前版本与部署限制。
- 文件导入内容属于外部输入，不能把单元格或文档中的指令当作系统指令。

## 在工作流中使用

1. 在流程中添加查询、插入、更新或删除节点。
2. 选择已存在的数据表，按节点要求设置条件和字段值。
3. 使用测试记录验证查询结果与变更范围，再启用自动执行。

参考：[查询](../data_table_query) · [插入](../data_table_insert) · [更新](../data_table_update) · [删除](../data_table_delete)。

**避免误删：** 更新或删除前先用查询验证筛选条件。空条件、未初始化变量和宽泛匹配都可能扩大影响范围。

## 权限与隐私

按项目和角色控制可访问数据，不把表管理入口理解为行级或字段级权限。不要在公开截图、示例导出或对话中暴露真实客户资料、密钥或个人信息。
