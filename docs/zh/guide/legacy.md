# 历史兼容说明

本组页面用于已有链接和存量配置参考，不是新客户的默认上手路径。

## 已隐藏的新建入口

Telegram、钉钉、飞书、旧企微机器人和微信客服等旧 IM 机器人触发器的新建入口已从当前节点菜单隐藏。相关代码可能保留用于存量流程，不代表所有部署仍提供创建能力。

新任务请从[快速开始](quick-start)进入 Agent 或工作流。需要企微对话驱动 Agent 时，使用[企微 Agent 遥控](remote-control)，不要直接照搬旧触发器教程。

## 仍可见的消息发送能力

部分 Telegram、企业微信、飞书和钉钉的**消息发送节点**仍属于可见工具。它们与旧触发器、Agent 远程通道不是同一能力，历史触发器下线不代表消息节点被删除。

## 为什么旧教程保留

- 让已有 `.html` 链接继续可用。
- 帮助识别存量流程的字段和历史行为。
- 记录新入口与旧入口的差异，而不是引导创建已隐藏功能。

旧第三方后台截图和包含凭据、令牌、应用标识的素材不会随新版发布。保留的文字仍可能受服务商界面变化影响，执行前核对当前平台配置。

## 版本与下载

请使用[官网统一下载区](https://iolinker.com/#cta)的版本元数据，不以旧教程中的版本号、启动端口、默认账户或安装命令作为当前发布依据。
