# 公共与专属技能

技能为 Agent 提供完成某类任务的方法和操作约定；它不等同于 MCP 工具，也不会替代模型配置。

## 公共技能

公共技能面向多个 Agent 复用。

1. 从工作台的技能市场或管理入口选择**新建技能**。
2. 填写名称和用途，上传 `SKILL.md` 或按界面方式添加内容。
3. 在 Agent 配置的技能区域勾选需要的公共技能。
4. 保存 Agent，用一个符合技能用途的任务验证结果。

修改公共技能可能影响多个 Agent。发布前检查适用范围，避免将项目秘密、账号或个人数据写入公共内容。

## Agent 专属技能

在目标 Agent 的**专属技能**区域新建或管理。每个专属技能有名称、描述、提示词、资源文件和工具绑定，工具绑定包含内置工具与工作流工具。

- **提示词**描述该 Agent 在特定任务中应遵循的方法。
- **资源文件**提供该技能所需资料，应检查大小、内容和敏感信息。
- **工具绑定**决定可执行能力，不是添加一段提示词就自动获得权限。

公共与专属同名时，专属版本优先；不要利用同名覆盖来绕过公共内容审查。

## 选择技能还是工具

- 需要“告诉 Agent 怎么做”：优先技能。
- 需要“让 Agent 调用外部系统”：优先 [MCP 工具](mcp-tools)。
- 需要“严格执行固定步骤”：优先[工作流](workflows)。
- 需要“检索内部文档”：优先[知识库](knowledge)。

删除技能前检查 Agent 引用。技能修改后用一个明确的成功标准验证，而不是只检查名称是否保存。
