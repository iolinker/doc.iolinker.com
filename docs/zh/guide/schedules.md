# Agent 定时任务

Agent 定时任务按计划向指定 Agent 提交一段任务提示词，不是工作流的 Crontab 触发器。

## 创建任务

1. 从 Agent 工作台进入**定时任务**，选择**新建任务**。
2. 选择 Agent，填写任务名称、可选分组／描述和明确的任务提示词。
3. 选择执行方式：执行一次、固定间隔、每天、每周或每月。
4. 按当前表单补充执行时间、间隔或星期／日期等字段，核对页面显示的下一次执行时间。
5. 保存，检查任务是否启用。

具体时间、时区和执行范围以当前界面及运行环境为准；不要假设关机期间的任务一定补跑。

## 立即执行与记录

- **立即执行**用于验证任务，不代表周期配置已成功运行。
- 任务行的**启用／暂停**控制后续计划；已结束任务不能简单当作普通启用任务处理。
- **执行记录**展示状态、时间和异常；有最近会话时可从任务行打开关联会话。
- 分组、搜索和状态筛选只影响管理视图，不改变任务提示词。

## 与工作流 Crontab 的区别

| 方式 | 执行对象 | 结果入口 |
| --- | --- | --- |
| Agent 定时任务 | 模型推理和已授权工具的动态任务 | 任务运行记录及关联 Agent 会话 |
| [工作流 Crontab](../trigger_crontab) | 已编排的节点流程 | 工作流执行记录 |

## 无人值守前的检查

先手动执行并检查结果。仅授权必要工具，限制目录和外部服务，设置清晰的任务边界。定时任务会持续使用模型与工具，可能产生费用或修改数据；异常时先暂停任务，再检查最近记录。
