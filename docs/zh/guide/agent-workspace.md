# 对话与会话

Agent 工作台用于执行需要模型推理和工具协作的开放式任务。Agent 会根据目标、上下文和工具结果动态规划并调整下一步，也可将工作流作为工具调用；工作流模式按预定义的节点、连线与分支规则组织可重复、受控的执行路径。顶部模式切换不会改变已有数据。

## 开始对话

1. 在 Agent 列表中选择已有 Agent，或按[创建 Agent](agents)新建一个。
2. 选择**开始对话**，输入目标、所需输入和期望输出。
3. 等待回答完成，检查工具卡片与结果，再发送后续指令。

模型未配置时，对话页会提供配置提示。先完成模型设置，不要把配置提示误当作 Agent 已可运行。

## 管理会话

左侧会话列表支持检索、置顶、归档和删除等入口，实际可用操作以当前角色和界面为准。

- **会话**保存任务上下文，可在 Agent 会话或链路入口继续查看。
- **归档**用于收起暂不活跃的会话，不等于删除。
- **删除**影响本地会话记录，操作前确认不再需要其中的上下文。
- **清空／编辑消息**可能改变后续上下文；重新执行前检查输入与授权。

## 查看执行链路

从对应会话进入链路，查看任务、子任务、工具调用与相关节点。定时任务有独立运行记录，可从任务行打开最近会话。

链路中的请求响应可能含业务内容，导出或分享前必须脱敏。日志中的错误不等于工具已经成功完成业务操作，应同时检查工具结果。

## 任务成功判断

- 回答与请求的目标、输入和输出一致。
- 工具卡片没有未处理的鉴权、网络或权限错误。
- 需要修改文件、调用外部服务或运行流程时，另行验证实际结果。
- 对开放式任务继续明确约束；不要把模型描述当作执行凭证。
