# 组合子 Agent

子 Agent 用于把相对独立的任务交给另一个 Agent 配置处理。它不是无限层级编排，也不等于子流程。

## 创建一个内置 Agent

1. 打开主 Agent 卡片的操作菜单，选择添加内置 Agent。
2. 在主卡的内置 Agent 区域打开其配置。
3. 写清该 Agent 负责的任务边界，只选择它需要的工具。
4. 回到主 Agent 配置，在子 Agent 区域选择这个内置 Agent。
5. 保存后从主 Agent 发起一个可验证的小任务，并在链路中检查子 Agent 调用。

当前入口只显示主 Agent 配置的直接子 Agent 选择，不承诺任意层级或递归调用。需要严格确定的步骤、顺序和失败分支时，优先使用[工作流](workflows)或[子流程节点](../sub_workflow)。

## 配置边界

- 内置 Agent 随主卡组织，不要把它当作独立 Agent 重复创建。
- 主 Agent 的任务分配、子 Agent 的指令和工具权限共同影响结果。
- 一个 Agent 被其他 Agent 引用时，先检查引用关系再删除或修改。
- 使用升级操作将内置 Agent 改为独立 Agent 前，确认后续归属和迁移范围符合预期。

## 排查

没有调用子 Agent 时，检查主 Agent 的子 Agent 选择、模型行为和任务描述；调用失败时检查子 Agent 的工具、模型和权限，不要仅靠增加循环或重试解决。
