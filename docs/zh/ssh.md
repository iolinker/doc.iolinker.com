## SSH远程执行

SSH远程登录机器，并执行Shell命令。

> 历史界面图片在复核并重拍前不展示，请按当前界面核对操作。

## 入参

> 历史界面图片在复核并重拍前不展示，请按当前界面核对操作。

### 凭据

可在【应用开发】>【凭据管理】里创建SSH凭据类型。需要配置如下几个选项：

- 主机。远程IP主机地址。
- 端口。SSH远程主机端口，默认22。
- 用户：登录账号。
- 密码：登录密码。

> 原截图含凭据、令牌或应用标识，已停止公开。请在对应平台自行创建秘密并填入本地配置。


### 命令行

远程到目标主机上执行的shell命令。例如：

```shell
ps -ef
```


## 出参

shell命令输出的字符串。
