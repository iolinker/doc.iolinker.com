# Legacy compatibility

These pages support existing links and installed configurations. They are not the default path for new customers.

## Hidden creation entries

New-creation entries for legacy Telegram, DingTalk, Feishu, WeCom robot and WeChat customer-service triggers are hidden from the current node menu. Retained code may support existing flows but does not prove that every deployment still offers creation.

Start new work with the [quick start](quick-start). To drive an agent through WeCom, use [WeCom agent remote control](remote-control) rather than copying an old trigger tutorial.

## Message-sending nodes remain distinct

Some Telegram, WeCom, Feishu and DingTalk **message-sending nodes** remain visible. They differ from old triggers and agent remote channels. Hiding a legacy trigger does not delete every messaging node.

## Why old articles remain

- Existing `.html` links continue to resolve.
- Existing workflows retain field and behavior references.
- The difference between current and historical entries is documented.

Old provider-console media and images containing credentials, tokens or application identifiers are not published with the new site. Written provider steps may also have changed; verify the current console before using them.

## Versions and downloads

Use the [official download section](https://iolinker.com/#cta) as the only maintained version source. Old tutorial versions, ports, accounts or commands are not a statement of the current release.
